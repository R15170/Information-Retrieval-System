# Information Retrieval Implementations

This folder contains the implementations developed during the Information Retrieval practical assignments.

The implementations are mainly written in Python and include the source code, test files, supporting data, and other files used during the practical work.

## Contents

The ZIP files contain the implementations for the different practical assignments.

The PR02 implementation contains the basic Information Retrieval functionality, including document processing and Boolean retrieval.

The PR03 implementation extends the system with additional functionality such as stemming, inverted lists, TF-IDF, Vector Space Model retrieval, and evaluation.

The folder also contains supporting files such as stemming data, ground truth data, and tests.
