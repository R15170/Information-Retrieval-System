# Information Retrieval System

This repository contains my work from the Information Retrieval practical assignments at university.

The project covers different concepts and techniques used in Information Retrieval, starting from basic document processing and Boolean retrieval and progressing to stemming, inverted indexes, Vector Space Models, TF-IDF, and evaluation using precision and recall.

## Practical Assignments

### PR01 – Introduction to Information Retrieval

The first practical assignment covers the basic concepts and design of an Information Retrieval system. It includes document processing, stop word removal, stemming, and different approaches to information retrieval.

### PR02 – Basic Information Retrieval System

The second practical assignment focuses on implementing a basic Information Retrieval system in Python. The implementation includes document processing, stop word elimination, and Boolean retrieval.

### PR03 – Stemming and Vector Space Model

The third practical assignment extends the Information Retrieval system with stemming, inverted lists, TF-IDF weighting, Vector Space Model retrieval, and evaluation using precision and recall.
