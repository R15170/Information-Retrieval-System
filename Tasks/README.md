# Information Retrieval Tasks

This folder contains the practical assignment documents for the Information Retrieval course.

The assignments cover the development of an Information Retrieval system across several practical tasks.

## Contents

### IR_PR01

Introduction to Information Retrieval concepts, system modelling, document processing, and retrieval methods.

### IR_PR02

Implementation of a basic Information Retrieval system, including document processing, stop word removal, and Boolean retrieval.

### IR_PR03

Extension of the Information Retrieval system with stemming, inverted indexes, Vector Space Model, TF-IDF, and evaluation using precision and recall.

The PDF files contain the corresponding task descriptions and reports.
